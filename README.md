# Puki Music for Windows

Klien desktop resmi **Puki Music** untuk sistem operasi Windows 10 & 11 (x64 / arm64).

## Fitur Utama
- **Two-Tier Artist Discography First**: Menampilkan album studio resmi musisi lokal & internasional langsung dari kanal artis terverifikasi YouTube Music (`WEB_REMIX`).
- **Fast Stream Engine**: Prioritas `itag 18` (MP4/AAC 7MB/s) + fallback `itag 251` (WebM/Opus).
- **Windows Integration**:
  - Dukungan penuh Windows Media Keys (Play, Pause, Next, Prev, Stop).
  - Integrasi SMTC (System Media Transport Controls) pada overlay volume Windows.
  - Minimasi ke System Tray di pojok kanan bawah.
- **Zero-Knowledge Sync Relay**: Sinkronisasi playlist & library secara real-time dengan aplikasi Android dan iOS.

## Instalasi
Unduh installer resmi `Puki-Music-Setup-x64.exe` dari [Releases](https://github.com/Queryzy/Puki-Music-Windows/releases) lalu jalankan installer.
